# 🏀 MVP Election System - Python

A Python program that automates the election of the **Most Valuable Player (MVP)** of a basketball tournament using journalists' votes.

---

## 📌 Project Description

At the end of a basketball tournament, sports journalists vote to select the player with the biggest impact on their team.

Each journalist chooses **three different players** according to preference:

🥇 1st choice → **5 points**  
🥈 2nd choice → **3 points**  
🥉 3rd choice → **1 point**

The player(s) with the highest total score are declared MVP.

---

# 🚀 Features

✨ The program can:

- 👥 Store player names
- ✅ Check that names contain only letters and spaces
- 🚫 Prevent duplicate player names
- 🗳️ Register journalists' votes
- ⭐ Calculate total points for each player
- 🏆 Find the MVP player(s)
- 📊 Handle multiple MVP winners in case of a tie

---
